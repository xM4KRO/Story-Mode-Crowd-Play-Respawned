# Contributing

We welcome reports, documentation fixes, and changes to the project-owned source. Please keep complete game archives, extracted stock scripts, private modified sidecars, generated patches, save files, and copies of the game out of issues and pull requests. Describe a problem with the season, game edition, menu path, expected behavior, and observed behavior. A redacted debug report can help; remove room codes, public tunnel links, and private addresses before posting it.

Test game-integration changes against lawful, supported game copies in isolated folders. In Season 2, start Crowd Play from the dedicated Crowd Play menu. Document any new third-party code or asset in [THIRD-PARTY-LICENSES.txt](THIRD-PARTY-LICENSES.txt), preserve its notices, and check the public tree for game-derived files before submitting a change.

The public checkout cannot rebuild the exact release installer without the private patch targets described in [BUILDING.md](BUILDING.md). Contributions can still improve the host, installer, web pages, documentation, and project-authored bridge code. We review proposed additions for compatibility with the noncommercial project license and third-party rights.
